## 4. 未完成与限制

### 未验证（需要外部条件）

- 真实 LLM / Embedding / Reranker / OCR / VLM 的连通性、维度、工具调用与质量。环境中有 `SILICONFLOW_KEY`，但未经用户授权未发起付费调用。
- macOS 构建、真机安装、中文目录、签名与公证。
- L（5 万页）/XL（20 万页）档；真实天津教材/真题基准。
- 复杂扫描件、表格、公式、图表的解析保真度。

### 已知实现限制

- 全量任务恢复时，已完成批次复用笔记，但**综合（synthesis）阶段会重新调用模型**，未缓存综合结果。
- 精准检索模式的暂停只在当前 Agent 调用结束后生效；不保存半程对话，继续会重新执行该轮。
- 任务费用仅在端点配置价格时估算；无价格时界面不显示费用，也不虚构。
- 局部重生成按标题定位章节；重复标题会产生歧义（取第一个）。
- 文档级 DOCX 模板（docxtpl）尚未在导出界面开放，当前使用内置样式。
- 旧向量行在“更换 Embedding → 重建 → 版本裁剪”组合下可能残留（不影响检索正确性，因按当前版本过滤）。
- 打包版 PDF 导出依赖本机 Edge/Chrome；开发版优先 Playwright。
- 安装包未生成：本机未安装 Inno Setup，且未获授权安装系统软件。

### 依赖与替换记录

- `regex==2026.11.24` 缺 win_amd64 wheel → 约束 `<2026.11.24`（uv.lock 固定 2026.11.23）。
- PDF 渲染：开发用 Playwright（Edge 通道）；打包版通过系统浏览器 `--print-to-pdf` 回退，避免捆绑 Chromium。
- 中文 FTS：SQLite 无内置中文分词 → jieba 预分词 + FTS5；trigram 作为补充查询路径。
