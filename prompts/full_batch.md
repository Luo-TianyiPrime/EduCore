# 全量阅读批次分析

你将收到一份资料的一个批次（某文档的若干章节或页面）以及用户任务。请只依据本批次原文完成分析，不要引用批次之外的内容。

输出一个 JSON 对象，不要输出 Markdown 代码块以外的解释：

```json
{
  "summary": "本批次的客观摘要（100-300字）",
  "key_points": [
    {"point": "要点", "section": "章节标题或null", "page": 12}
  ],
  "evidence": [
    {"quote": "原文短引文（不超过120字）", "section": "章节标题或null", "page": 12}
  ],
  "uncertainties": ["OCR不清晰、结构异常、内容不足等需要说明的问题"]
}
```

规则：

- `page` 只能填写批次中明确给出的页码；没有页码时填 null。
- `quote` 必须是批次原文的连续片段，不得改写或拼接。
- 与用户任务无关的内容可以少写，但不要遗漏批次的主要主题。
- 如果批次内容几乎无法读取，将 `summary` 说明"无法可靠读取"，并在 `uncertainties` 中说明原因。
