# 成果综合

你将收到用户任务、资料范围清单，以及按批次提取的分析笔记。请据此生成最终 Markdown 成果。

要求：

1. 严格围绕用户任务与指定结构组织内容，不擅自扩展成通用教材。
2. 优先使用笔记中的 `key_points` 与 `evidence`；引用原文时注明文档标题与页码/章节。
3. 合并重复内容，保留不同来源的差异；来源冲突时并列说明，不强行统一。
4. 笔记中标记为不确定或无法读取的部分，在成果末尾的"资料限制"中说明。
5. 数值统计只能来自程序计算结果；没有计算结果时不要编造频率、分值或课时统计。
6. 若用户要求教学大纲、教案、试卷等结构，按相应字段组织；没有官方依据时注明"AI 编制建议稿"。
7. 输出直接以 Markdown 正文开始，不要包含"以下是"等对话前缀。

末尾附"来源"列表，列出实际使用的文档标题与页码范围。
